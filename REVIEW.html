2. 핵심 사용자 흐름

  1. 홈 진입: ants와 FIRST LIGHT가 향수 브랜드·제품임을 이해한다.
  2. 스크롤 경험: 물방울에서 아침빛 속 향수병으로 이어지는 장면을 본다.
  3. 상품 탐색: 홈의 향 소개·일상 장면과 6종 컬렉션을 보거나 헤더의 전체 향수·향별로 찾기·검색으로 원하는 상품을 찾는다.
  4. 상품 상세: 각 제품의 이름·향의 느낌·50mL·해당 가격을 읽고 수량을 선택한다.
  5. 장바구니: 여러 향수의 개별 수량·금액과 전체 합계를 확인하고 한 상품씩 수정 또는 삭제한다.
  6. 모의 주문: 개인정보 입력 없이 주문 내용을 확인한다.
  7. 모의 주문 완료: 실제 결제·주문 접수가 없었다는 안내와 체험한 상품 정보를 확인한다.

사용자는 스크롤 연출 전체를 보지 않아도 상품 상세에 접근할 수 있다. 상품 상세와 장바구니에서 뒤로 돌아갔을 때 데모 선택 상태가 불필요하게 사라지지 않아야 한다.

  • 경계: 강제 reduced/fallback 브라우저 검수와 실제 스마트폰·OS 설정 검수는 별도다. 파일의 24fps·압축 용량을 탐색 성능이나 사용자 최종 수용의 통과 판정으로 사용하지 않는다.

D-04 대표 사진 확대 · 현행

제품의 실제 스튜디오 사진을 안정된 밝은 창 안에서 살펴보는 단일 native dialog다. FR-14에 대응하며 product-detail.mjs가 조작하고 기존 색·두 글꼴·8/12/16px 모서리를 재사용한다. 새 이미지·캐러셀·확대 라이브러리를 만들지 않는다.

  • 열기·fallback: 사진의 기본 클릭/Enter는 다른 열린 dialog를 닫고 showModal()로 현재 제품명을 가진 창을 열며 닫기 버튼에 포커스를 둔다. body 스크롤을 잠그고 배경은 native modal의 inert 영역으로 남긴다. 수정키 클릭은 가로채지 않는다. JavaScript 또는 showModal을 사용할 수 없으면 같은 사진 href의 원본 링크가 작동한다. 이 fallback은 소스로 확인했으며 실제 미지원 브라우저 검수는 미확인이다.
  • 준비·성공: 시작할 때 전체 보기로 되돌리고 사진을 준비하는 aria-busy와 ‘사진을 준비하고 있어요.’를 표시하며 크기 버튼을 비활성화한다. 이미지가 로드되면 사진 전체를 contain으로 맞추고 크기 버튼을 활성화하며 ‘사진 전체를 화면에 맞춰 보고 있어요.’를 알린다. 준비/성공 안내는 role=status·aria-live=polite다.
  • 전체/원본: ‘원본 크기’는 aria-pressed=true와 ‘전체 보기’로 바뀌고 실제1120×1400px 이미지를 제한 없이 표시한다. 포커스 가능한 사진 영역 안에서만 가로/세로 스크롤·키보드/터치로 살펴보고 ‘사진 영역을 스크롤해 자세히 살펴보세요.’를 안내한다. 전환 때 사진 영역의 스크롤은0으로 돌아온다. 확대를 보간한 고해상도 파일로 주장하지 않는다.
  • 오류·다시 불러오기: 실패한 이미지는 숨기고 role=alert의 ‘사진을 불러오지 못했어요.’와 기존 주 버튼 ‘다시 불러오기’를 보여준다. 크기 버튼은 비활성화하고 닫기와 사진 영역은 유지한다. retry는 숨겨질 버튼에서 지속되는 viewer로 포커스를 먼저 옮긴 뒤 같은 원본 링크를 다시 요청한다. 성공 또는 다시 실패해도 그 viewer가 DOM에 계속 남아 포커스를 유지한다. 실제 실패→성공과 보이는 포커스는 검수했고 반복 실패 재현은 미확인이다.
  • 키보드·닫기: 매 Tab에서 현재 보이며 활성화된 버튼과 tabindex=0 viewer를 수집한다. 끝에서 Tab은 처음으로, 처음에서 Shift+Tab은 끝으로 순환하며 실패 상태의 retry도 포함한다. viewer에는 안쪽3px 간격의2px focus 선, 링크/버튼에는 기존 바깥4px 간격의2px 선을 표시한다. 닫기·Esc·PC 창 바깥 클릭으로 닫으며 전체 보기/내부 스크롤을 초기화하고 다른 열린 dialog가 없으면 body 잠금을 해제한다. 원래 사진 링크에 preventScroll 포커스를 돌려 페이지 위치를 유지한다.
  • 형태·밀도: 창/사진틀은 각각16px/12px 모서리와 surface/bg, 크기 버튼은8px 모서리·1px control-border·최소44px 높이다. 사진틀은 남은 높이의 scroll region이며 실패 내용은24px 안쪽 여백·최대28em·문장 뒤20px다. 확대/크기 버튼 hover는 control-hover, 비활성 크기 버튼은 opacity.5와 실제 조작 차단을 함께 사용한다. 정확한 크기·여백·글자 단계는 앞의 Layout·Typography와 YAML을 따른다.

sidecar의 ‘Product Image Viewer’는 실제 FIRST LIGHT 사진을 내장한 열린 native dialog의 정적 내용 미리보기다. hover/focus는 미리보기에서도 보이며 전체/원본 전환·retry·modal 잠금·닫기·포커스 복귀는 실제 사이트의 MJS 계약이다.

D-05 세 가지 향 인상과 어울리는 하루 · 현행

D-07 일상 세 장면과 병/라벨 디테일 · 현행

제품별 ritualTitle과 ritual의 세 쌍을 dl/dt/dd 세 행으로 제공한다. 각 행은 위1px 구분선·상하24px, 제목 뒤12px이며 캐러셀·선택·호버 상태가 없다. PC는 왼쪽 일상 세 장면/오른쪽 병 사진, <=819는 같은 순서의 한 열이다. 사진 아래28px 뒤 ‘가까이에서 보는, 작은 형태.’와 해당 제품 bottle 문구를 둔다. 소제목 뒤16px, 캡션 최대36rem이다. 병 사진은 기존 스튜디오 원본의1.45배 CSS 크롭이며 라벨·유리·뚜껑의 시각적 인상을 설명한다. 새로운 재질·제조·성분 증명을 주장하지 않는다.

D-08 가까운 향의 구체적인 비교 · 현행

두 상품의 실제 studio 사진·영문/한글 이름·계열·기존 scent를 나란히 두고, 아래 해당 compareText와 compareId의 실제 /product/{id}/ 링크를 제공한다. 고정된 ‘우디도 보세요’ 같은 공통 문구 대신 제품별 인상의 차이를 읽는다. 링크는 비교 대상의 한글명과 ‘도 살펴보기’이며 장바구니를 바꾸지 않는 native 링크다. 두 제품/차이/연결 순서를 모바일 한 열에서도 유지한다.

C-01 장바구니

  • 목적·메시지: 선택한 상품과 수량·합계를 확인한다. FR-05 연결.
  • 자료·배치: 제품 축소 이미지, 이름·50mL·단가, 수량 조작, 삭제. PC는 왼쪽 상품 행·오른쪽 요약. 모바일은 상품 → 요약 → 버튼.
  • 우선순위: 선택 상품 → 수량 → 총 상품 금액 → 모의 주문 안내 → ‘모의 주문하기’. 상품명은 기존 제목 굵기400을 사용한다.
  • 금액: 각 제품의 catalog.mjs 단가 × 해당 수량을 합산. 배송·결제 수수료는 계산하지 않고 ‘실제 결제와 배송이 없는 모의 주문입니다.’ 한 문장으로 안내한다.
  • 상태: 빈 장바구니에는 ‘아직 담은 향수가 없어요.’와 ‘좋아하는 향을 골라 장바구니에 담아보세요.’·‘전체 향수 보기’. 상품·요약·주문 버튼을 숨기고 상품 복귀 행동을 제공한다.
  • 모바일: 수량과 삭제 조작의 44px 영역 확보. 819px 이하 요약과 주문 버튼은 일반 흐름에 놓고 고정하지 않는다.

O-01 모의 주문 확인

  • 목적·메시지: 실제 입력 없이 구매 과정의 마지막 선택을 체험한다. FR-06 연결.
  • 구성: 상품·수량·총 상품 금액, ‘실제 결제와 배송이 없는 모의 주문입니다.’ 한 문장의 요약 안내, 장바구니 수정 링크.
  • 개인 정보: 이름·전화·주소·카드 정보를 받지 않는다. 설명 제목은 ‘선택한 향을 확인해 주세요.’, 본문은 “‘모의 주문 완료하기’를 선택하면 체험이 완료됩니다.”와 ‘개인정보 입력이나 실제 주문 접수는 없습니다.’ 두 짧은 줄이다. 버튼의 위치를 방향으로 설명하지 않는다.
  • 배치: PC는 주문 정보와 요약을 두 영역으로, 모바일은 한 열로 배치한다. 설명 제목 PC24px/1.4·아래16px, <=600:22px/1.3이며 본문16px/1.65·margin0·최대36em이다.
  • 버튼: ‘모의 주문 완료하기’ → O-02. 빈 장바구니 접근 시 ‘확인할 상품이 없어요.’와 ‘먼저 좋아하는 향수를 장바구니에 담아주세요.’·‘전체 향수 보기’를 제공한다.

O-02 모의 주문 완료

  • 목적·메시지: 체험의 결과를 분명히 알려준다.
  • 제목: ‘모의 주문을 완료했어요.’를 두 줄로 읽고 아래에 ‘선택한 향과 수량을 확인해 보세요.’와 ‘실제 결제와 배송은 진행되지 않습니다.’를 둔다.
  • 구성: 완료 시점의 모든 제품·각 수량·각 금액·총 수량과 종류·체험 총금액, 홈과 전체 향수 복귀 행동. 별도 중복 completion-note는 제거했다.
  • 상태: 완료 버튼을 즉시 비활성화하고 상품 번호·수량 결과를 보존한 다음 장바구니를 비워 완료 주소로 이동하고 scrollY0으로 맞춘 뒤 재로드한다. 결과는 세션 저장과 완료 페이지의 이동 기록에서만 읽는다. URL 수량이나 fragment만으로 완료 결과를 만들지 않는다. 직접 진입·새 세션에서는 실제 완료처럼 보이게 하지 않고 ‘완료한 모의 주문이 없어요.’와 ‘좋아하는 향수를 고르고 모의 주문을 진행해 보세요.’·‘전체 향수 보기’ 링크를 표시한다.
  • 모바일: 결과·제품 요약·복귀 행동 순서, 헤더·푸터의 공통 규칙 유지.

UI-03~UI-06와 상태 계약 · 구현

UI는 화면에서 보고 조작하는 요소다. 공통 메뉴/검색/목록/상품/장바구니/완료는 shop.mjs, 가상 제품 사실·검색/정렬은 catalog.mjs, 제품별 검증·합계·저장 호환은 cart.mjs를 재사용한다.

번호·구성요소 현재 구조·상태 동작·모바일
UI-01 내비게이션 전체 향수·향별 탐색·브랜드·검색·장바구니 <=959 로고/검색/장바구니/메뉴; 모든 조작44px

수량은 한 제품마다1~9개, 최대6행·총54개다. 전체9개 제한이 아니다. 합계는 sum(catalog.price × item.quantity)이며 FIRST LIGHT2개+QUIET WOOD1개는138,000+75,000=213,000원이다. 각 수량 수정·행 삭제는 다른 상품을 보존한다. 잘못된 draft를 다른 값으로 바꾸거나 재렌더로 덮어쓰지 않고 항목 옆 오류와 수정 경로를 유지하며 확인 링크를 inert/aria-disabled 처리한다. 삭제 뒤 다음/이전 남은 상품 링크에, 마지막 삭제 뒤 빈 상태 제목에 포커스를 둔다. 결과를 토스트에만 남기지 않는다.

저장 키 ants.cart.v1은 유지하되 새 payload는 {version:2, items:[{id,quantity}]}만 쓴다. 이전 {product:'first-light',quantity:0..9} 장바구니·이전 완료 결과를 호환해 읽는다. id 중복·존재하지 않는 제품·잘못된 수량/형식은 유효 결과로 사용하지 않는다. 저장한 가격은 무시하고 catalog.mjs에서 고정 가격을 조회한다. 차단/손상 시 경고와 안내를 보이고 메모리·같은 탭 내부 링크·검색 submit의 history state로 흐름을 유지한다. 새 탭·이동 기록 삭제까지 보존을 보장하지 않는다.

완료는 모든 items의 snapshot을 sessionStorage ants.result.v1 또는 완료 history state에 남기고 장바구니를 비운다. 완료 버튼을 먼저 비활성화해 중복 처리를 막고 /complete/의 맨 위로 이동한다. 결과 없는 직접 진입은 빈 결과와 전체 향수 복귀를 제공한다. 주소/fragment만으로 결과를 만들지 않는다. 개인/결제 정보·실제 주문번호·외부 전송은 없다.

이전 ‘단일 상품이라 검색/필터 불필요’는 교체된 범위다. 현행은 향별 팝업·검색 dialog·분류/정렬을 실제 제공한다. 여섯 상품에는 페이지네이션·별도 sidebar·슬라이더·캐러셀을 추가하지 않았다. 이는 모든 향후 화면에 대한 금지가 아니다.

Do's and Don'ts

Do:

  • Do ‘물방울로 여는 아침’, 밝은 청백색과 깊은 청록, 선택한 두 글꼴을 다음 화면까지 유지한다.
  • Do 같은 진행률에서 PC·모바일의 작은 표면 물방울 접사·같은 병 전체 공개·제품 정보와 역방향 순서를 비교한다.
  • Do 실제 한글·가격·데모 안내와 44px 조작 영역을 넣은 화면에서 겹침·잘림·포커스를 확인한다.
  • Do 정적 대체 상태의 실제 제품 패널과 loading/ready 영상 모드의 가상 제품 마커를 구분해 링크·직접 해시·메뉴 이동을 검증한다.
  • Do 새 한글 문구를 글꼴 서브셋에 포함하고 출처·라이선스·이미지 메타데이터를 보존한다.
  • Do 홈→목록/검색/향별 탐색→각 상품→다품목 장바구니→확인→완료와 빈 결과·제품별1~9·혼합 합계·저장 호환/차단·중복 완료를 변경 후 함께 확인한다.
  • Do 여섯 스튜디오 사진의 같은 병·조명·4:5 비율·크기와 각 제품 이름/가격의 대응을 유지한다.
  • Do 향 찾기의 선택 전/체크/키보드/인접 오류·이전 답 보존·여섯 추천·초기화와 해당 상세 링크를 함께 확인한다.

Don't:

  • Don't 글자를 병·뚜껑·강한 반사광 위에 겹치거나 작은 저대비 설명으로 축소한다.
  • Don't 모든 구간을 같은 카드 목록이나 반복되는 긴 고정 연출로 만든다.
  • Don't 향수와 관계없는 장식이나 확정하지 않은 개미 그림·과도한 구매 압박을 추가한다.
  • Don't 확인되지 않은 성분·지속력·효능·안전성·리뷰·배송 약속·실제 연락처를 만들어 넣는다.
  • Don't 모바일에서 호버에만 의존하거나 움직임 줄이기·실패의 정적 대체 화면을 정상 모바일의 기본 연출로 바꾼다.
  • Don't 미제출 계획 프롬프트를 실제 적용 지시로 기록하거나 이전 제한 수정의 PASS·파일의 24fps·현재 캡처 범위의 ship을 실제 운영 결제·전체 기기 성능·사용자 최종 미적 수용의 통과로 표현한다.

현재 남은 위험·미확인 사항은 Overview의 검토 범위를 따른다. 작업 상태와 Git·배포 보고는 DECISIONS.md에 별도로 기록한다.
