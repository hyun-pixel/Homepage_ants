완료: 체험 완료 안내, 선택한 모든 상품, 총 개수·종류·금액, 전체 향수/홈 이동. 실제 결제·주문 접수 없음 표시. 선택이 없는 경우에는 빈 상태와 상품 탐색 버튼을 보여줍니다.

이 아래의 초기 한 제품 설계는 인터뷰 이력입니다. 현재 상품 수·헤더·검색·구매 흐름은 이 6종 확장안과 최신 PRD/디자인 명세서를 따릅니다.

구매 흐름　홈 → 상품 상세 → 장바구니 → 모의 주문 확인 → 모의 주문 완료

01 홈

브랜드 경험 → 향 이해 → 일상과의 연결 → 상품 상세 이동. 첫 시안 범위는 헤더·전체 히어로·향 소개까지입니다.

02 상품 상세

제품명·향·용량·가격·수량을 한 흐름으로 읽고 장바구니에 담습니다. 단일 용량이므로 선택 목록은 추가하지 않습니다.

실제 제작에서는 담기 후 상품 상세를 유지하고 토스트·수량 표시·장바구니 보기로 결과를 안내합니다. 위 버튼은 설계상의 다음 화면을 보는 링크입니다.

03 장바구니

상품·수량·합계를 확인하고 수정합니다. 가격 계산은 단가 69,000원 × 수량입니다.

04 모의 주문 확인

개인정보를 입력하지 않고 선택한 제품과 금액을 확인한 뒤 모의 주문을 완료합니다.

05 모의 주문 완료

체험 완료 사실과 실제 거래가 없다는 안내를 함께 보여줍니다.

직접 완료 주소로 진입했거나 기록이 없는 경우에는 ‘확인할 데모 주문이 없습니다’와 상품 이동 링크를 보여주는 상태를 별도로 구현합니다.

흑백 설계도 확인과 실제 홈페이지의 반응형·애니메이션·구매 동작 검수는 별개의 단계입니다.

제품별 상세 이야기 · FR-15

구매 정보의 향 이야기 보기 → 각 향의 장면 사진과 고유 이야기 → 첫인상·중심·여운 → 어울리는 하루 → 관련 상품 → 간결한 공통 푸터. (이전 FR-15 흐름이며 아래 FR-16에서 확장)

PC는 사진7:문구5의 두 열, 향 인상3열이다. 모바일은 사진·이야기 순서로 쌓고 향 인상은 레이블/설명 한 행씩 배치한다. FIRST LIGHT의 기존 두 이야기 구간은 보존한다.

상세 본문 확장 · FR-16

구매 정보 → 기존 장면/향 인상 → 큰 제품 캠페인 사진 → 고유 제목과 두 문단 → 세 가지 일상 장면과 병/라벨 근접 사진 → 두 향 비교와 상대 상품 이동 → 관련 상품 → 로고/메뉴 푸터.

PC: 캠페인 사진은 전체 폭, 아래 제목과 본문은 두 열. 일상5:근접 사진7, 비교 상품은 두 열이다. 모바일: 같은 순서로 한 열을 유지하고 캠페인은4:5로 잘라 병 전체를 보존한다.320px에서도 비교 상품은 한 행씩 배치한다. 기존 사진 확대와 구매 버튼을 유지한다.

사용자 첨부의 ‘체험 전, 알아두세요’ 전체와 공통 푸터의 두 안내 문장/구분선은 삭제했다. 다른 위치에 대체하지 않는다.

현재 전체 마감 · FR-17

홈의 장면과6종 목록 → 검색/향 찾기 → 제품 사진·향·용량·가격·수량·담기 → 여러 상품 장바구니 → 모의 주문 확인 → 모의 주문 완료.

상품 상세는 반복 데모 안내 없이 향과 선택 정보에 집중한다. 장바구니/주문 단계의 한 문장과 모의 주문 버튼/완료 제목으로 실제 결제·배송이 없음을 전달한다. 삭제한 FAQ·푸터 안내·복귀 링크·가상 해석 문장은 복원하지 않는다.

PC는 기존 구매7:5/주문7:4 두 열을 유지한다. 모바일은 사진·정보와 상품·합계를 순서대로 쌓고 상품 상세의 담기 버튼은 기존 본문 버튼 노출에 맞춰 고정 표시를 조절한다. 빈 상태의 이동은 전체 향수 보기로 통일한다. 과거 도식에 다른 안내가 있으면 이 현행 정정이 우선한다.
